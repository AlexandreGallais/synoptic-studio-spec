# Screens of Metadata

> [Home](../../README.md) › [Design system](../README.md) › Screens of Metadata

The screens of Metadata as drawn in Figma, exported as SVG, with the id of each frame. What each control does is in [Screens of Metadata](../../screens/metadata.md); this folder shows how they look, made only of the [template](../templates/editor/README.md) and the components of the design system.

Figma: page Metadata (`630:109`). Each screen is an instance of `template/editor`, named `MD-xx · <screen>`, then `· <state>` for each content state. The prototype has one starting point per screen.
