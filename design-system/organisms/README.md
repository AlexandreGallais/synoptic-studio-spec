# Organisms

> [Home](../../README.md) › [Design system](../README.md) › Organisms

Components made of molecules and atoms that form a whole part of a screen. One sheet per organism (`<organism>.md`); the table of its variants and states, exported from Figma, is in [images](images/) (`table-<organism>.svg`) (Product Owner, 2026-11-23). Only the organisms the screens of Metadata use are here (Product Owner, 2026-11-22).

Figma: page [Organisms](https://www.figma.com/design/2hW8t5CgVru1VFbQZ1yETL/?node-id=630-107) (`630:107`). The rules every component follows are in [Components](../03-components.md).
