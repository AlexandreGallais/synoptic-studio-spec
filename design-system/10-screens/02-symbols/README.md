# Screens of Symbols

> [Home](../../../README.md) › [Design system](../../README.md) › [Screens](../README.md) › Screens of Symbols

The screens of the symbol mode as drawn in Figma, one page per group of screens, each with a table of its Figma frames. What each control does is in [Screens of the symbol editor](../../../screens/symbols.md); these pages show how they look, made only of the [template](../../09-templates/editor.md) and the components of the design system.

Figma: page [Symbols](https://www.figma.com/design/2hW8t5CgVru1VFbQZ1yETL/?node-id=757-16360) (`757:16360`). Each screen is an instance of `template/editor`, named `SY-xx · <screen>`, then `· <state>` for each content state. The older wireframes of the page Spec stay there as a source, not as the design.
