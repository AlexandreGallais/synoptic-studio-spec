# Screens of Metadata

> [Home](../../../README.md) › [Design system](../../README.md) › [Screens](../README.md) › Screens of Metadata

The screens of Metadata as drawn in Figma, one page per part of a type, each with a table of its Figma frames, then its screens exported as SVG (in [images](images)). What each control does is in [Screens of Metadata](../../../screens/metadata.md); these pages show how they look, made only of the [template](../../09-templates/editor.md) and the components of the design system.

Figma: page [Metadata](https://www.figma.com/design/2hW8t5CgVru1VFbQZ1yETL/?node-id=630-109) (`630:109`). Each screen is an instance of `template/editor`, named `MD-xx · <screen>`, then `· <state>` for each content state. The prototype has one starting point per screen.
