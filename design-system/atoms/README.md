# Atoms

> [Home](../../README.md) › [Design system](../README.md) › Atoms

The smallest components: each does one thing and holds no other component but an icon. One folder per atom, with its sheet (`README.md`) and the table of its variants and states exported from Figma (`table.svg`). Only the atoms the screens of Metadata use are here (Product Owner, 2026-11-22).

Figma: page Atoms (`630:105`). The rules every component follows are in [Components](../04-components.md).

## Sheets

| Atom | What it is | Section of the page |
| --- | --- | --- |
| [button](button/README.md) | A text button that starts an action. | Actions |
| [icon-button](icon-button/README.md) | A square button that shows one icon. | Actions |
| [toggle-button](toggle-button/README.md) | An icon button that stays on or off. | Actions |
| [checkbox](checkbox/README.md) | A box that turns an option on or off. | Selection |
| [radio](radio/README.md) | A round button to pick one option of a small set. | Selection |
| [colour-swatch](colour-swatch/README.md) | A sample of a colour of a palette, to pick it. | Selection |
| [text-input](text-input/README.md) | A field of one line for a text. | Inputs |
| [number-input](number-input/README.md) | A field for a number with its unit, or a value taken from a signal. | Inputs |
| [text-area](text-area/README.md) | A field of several lines. | Inputs |
| [select-trigger](select-trigger/README.md) | The closed part of a select. | Inputs |
| [drag-handle](drag-handle/README.md) | The grip that moves a line. | Support |
| [label](label/README.md) | The name of a field outside a table. | Support |
| [tooltip](tooltip/README.md) | A small bubble that names an icon. | Support |
| [scrollbar](scrollbar/README.md) | The thumb of a list or a table that scrolls. | Support |
| [divider](divider/README.md) | A thin line between groups. | Support |
| [column-header](column-header/README.md) | The name of a column of a table. | Support |

The icons are atoms too: they have their own folder, [Icons](../icons/README.md).
