# Atoms

> [Home](../../README.md) › [Design system](../README.md) › Atoms

The smallest components: each does one thing and holds no other component but an icon. One sheet per atom (`<atom>.md`); the table of its variants and states, exported from Figma, is in [images](images/) (`table-<atom>.svg`) (Product Owner, 2026-11-23). Only the atoms the screens of Metadata use are here (Product Owner, 2026-11-22).

Figma: page [Atoms](https://www.figma.com/design/2hW8t5CgVru1VFbQZ1yETL/?node-id=630-105) (`630:105`). The rules every component follows are in [Components](../03-components.md).

## Sheets

| Atom | What it is | Section of the page |
| --- | --- | --- |
| [button](button.md) | A text button that starts an action. | Actions |
| [icon-button](icon-button.md) | A square button that shows one icon. | Actions |
| [toggle-button](toggle-button.md) | An icon button that stays on or off. | Actions |
| [checkbox](checkbox.md) | A box that turns an option on or off. | Selection |
| [radio](radio.md) | A round button to pick one option of a small set. | Selection |
| [colour-swatch](colour-swatch.md) | A sample of a colour of a palette, to pick it. | Selection |
| [text-input](text-input.md) | A field of one line for a text. | Inputs |
| [number-input](number-input.md) | A field for a number with its unit, or a value taken from a signal. | Inputs |
| [text-area](text-area.md) | A field of several lines. | Inputs |
| [select-trigger](select-trigger.md) | The closed part of a select. | Inputs |
| [drag-handle](drag-handle.md) | The grip that moves a line. | Support |
| [insert-button](insert-button.md) | A small round + that inserts a line or a column of a table. | Support |
| [label](label.md) | The name of a field outside a table. | Support |
| [tooltip](tooltip.md) | A small bubble that names an icon. | Support |
| [scrollbar](scrollbar.md) | The thumb of a list or a table that scrolls. | Support |
| [divider](divider.md) | A thin line between groups. | Support |
| [column-header](column-header.md) | The name of a column of a table. | Support |

The icons are atoms too: they have their own folder, [Icons](../icons/README.md).
