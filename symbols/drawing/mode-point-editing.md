# Point editing mode

> [Home](../../README.md) › [Symbols](../README.md) › [Drawing](../02-drawing.md) › [Modes](modes.md) › Point editing

Status: draft, from the Product Owner's description of 2026-11-11. Not validated.

The mode in which the points of a path are edited.

## Rules

- The tool bar keeps [Select](tool-select.md), [Hand](tool-hand.md) and [Pen](tool-pen.md). The Rectangle, Ellipse, Polygon and Text tools disappear.
- Select picks points and handles, one or several, and moves them.
- Points can be added and removed.
- The Pen starts from an existing point to trace another one.
