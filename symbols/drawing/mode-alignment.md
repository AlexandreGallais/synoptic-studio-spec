# Alignment mode

> [Home](../../README.md) › [Symbols](../README.md) › [Drawing](../02-drawing.md) › [Modes](modes.md) › Alignment

Status: draft, from the Product Owner's description of 2026-11-11. Not validated.

The mode in which shapes are placed in relation to each other.

## Rules

- The tool bar keeps only [Select](tool-select.md) and [Hand](tool-hand.md).
- Select picks the shapes to place in relation to each other.
- The right-hand panel becomes an alignment panel for the selected shapes.
- The mode is only for placing shapes, not for drawing them.
