# Rectangle tool

> [Home](../../README.md) › [Symbols](../README.md) › [Drawing mode](README.md) › Rectangle

Status: draft, from the Product Owner's description of 2026-11-11. Not validated.

## Rules

- Draws a rectangle by dragging. It becomes a path.
- Its corner radius is set in the right-hand panel.
- While drawing, a modifier key (Shift or Ctrl) forces the width and the height to be equal: a square.
- The panel has a visible option that links the width and the height, for the same result.
