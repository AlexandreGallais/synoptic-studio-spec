# Expert menu

> [Home](../../../README.md) › [Symbols](../../README.md) › [Editor](../README.md) › Expert menu

Status: draft, from the Product Owner's description of 2026-11-11. Not validated.

The expert menu is not a tool. It is a menu with tools inside, for what is not everyday drawing.

## Rules

- It is a menu opened with three small dots. It lists every "expert" entry.
- Choosing an entry shows a **second tool bar**, with the tools of that entry. The user can hide this second bar, since it is not always useful.
- Choosing an entry acts a bit like a mode: what the editor does depends on what the user wants to do. Whether it is really a mode is not decided.
- The entries work on shapes that already exist.
