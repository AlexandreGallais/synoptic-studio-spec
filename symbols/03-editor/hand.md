# Hand tool (removed)

> [Home](../../README.md) › [Symbols](../README.md) › [Editor](README.md) › Hand

Status: removed by the Product Owner on 2026-11-26 (decision 0109).

## Rules

- There is **no Hand tool**, in any mode: the view moves with the middle button of the mouse held down, the scroll wheel, the trackpad and the scroll bars (see [Moving around the drawing](README.md#moving-around-the-drawing)).
- Why: one way to move, so that users learn the mouse, the zoom and the scroll bars (Product Owner, 2026-11-26: "il faut habituer les gens à utiliser le zoom pour se déplacer").
- The Run mode, whose only tool was the Hand, has no tool bar (assistant's proposal).
