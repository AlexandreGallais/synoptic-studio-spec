# controls

> [Home](../README.md) › Controls

Status: draft. Not validated.

The controls shared by the whole application: a number field, a text field, and the other controls that every part uses. Each one is a single component of the design system, with the same behaviour on every screen, in Metadata, in the symbol editor and in the synoptic.

## What it contains

| File | What it holds |
| --- | --- |
| [Number and text fields](number-and-text-fields.md) | The number field (arrows, step, faster step with a key, no pixel unit) and the text field, shared by every screen. |
| [Size fields](size-fields.md) | Width and height on one line, each Fixed or Hug with a small menu, the value always shown. |
| [Colour field](colour-field.md) | A swatch and two inputs, colour │ opacity; the swatch opens the popup of the kinds of fill. |
| [Segment list](segment-list.md) | The dashed body of a pipe: one line per segment (colour, length), + and −. A border has no dashes (2026-11-26). |
